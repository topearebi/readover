One token for all your repos. Kept only on this device.

How to get a token
  1. Open GitHub's token page (name and permission are filled in).
  2. Under Repository access, choose All repositories, or just your notes and books repos.
  3. Generate it, copy it, and paste it here.

Keep your notes safe

Right now your notes live only in this browser. If its data is cleared, they're gone. On GitHub they become plain Markdown files in a private repository only you can see. GitHub is free, and your favourites and reading positions will follow you to any device.

  1. Create a private repository

    It's filled in for you: just press Create repository. Already have one for notes? Skip this.

    Create it on GitHub

  2. Create a token for Readover

    Also filled in. Under Repository access, choose Only select repositories and pick your notes repository. Then press Generate token and copy it.

    Create a token

  3. Connect

Your token stays in this browser. Readover only talks to GitHub.
